# Upload this profile to GitHub

1. Sign in to GitHub and open **https://github.com/milan-sahukar**.
2. Open the repository named **milan-sahukar**. This must be a *public* repository with the same name as your username. If it does not exist, create a new public repository named `milan-sahukar` and tick **Add a README file**.
3. On the repository page, choose **Add file → Upload files**.
4. Extract this ZIP on your computer. Upload `README.md` and the complete `assets` folder (keep the folder structure). Do not upload only the ZIP file.
5. If GitHub asks whether to replace the existing README, confirm. Enter commit message `Add animated GitHub profile` and choose **Commit changes**.
6. Open **https://github.com/milan-sahukar** to view your profile.

## Important
- The profile uses five self-contained SVG sections and local PNG assets.
- The photo cutout uses your supplied formal portrait; the same exact-face cutout is reused in the connect section to avoid inventing a different face or hand pose.
- Unverified GitHub stats and unconfirmed social URLs are intentionally omitted. Add exact social links later if you want them shown.
- GitHub may not animate every SVG feature in every viewer; the text and layout remain readable without animation.
